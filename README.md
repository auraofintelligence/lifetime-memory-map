# Lifetime memory map

An illustrated, editable map of Luke Nathan Hayes’s life, residences, journeys and memory fragments.

**Work in progress:** this is not yet a complete map. Evidence sources and memory fragments are still to be added, and dates confirmed. It is essentially a true and accurate account of Luke’s life to date, as he remembers it. Landscapes are illustrative rather than exact geography.

[Open the public map](https://auraofintelligence.github.io/lifetime-memory-map/) · [Connected projects](https://auraofintelligence.github.io/lifetime-memory-map/connections.html) · [Licence](LICENSE)

## Explore and contribute memories

Eight views cover the lifetime overview, all places lived, early memories, Queensland, the United Kingdom, northern Australia, island and city life, and Asia and journeys. The current edition contains 359 entries, including 37 residence entries with repeat stays preserved.

Select a card to read, fix or remove an entry. Add new fragments or residences using Add a memory. Removed entries can be restored. Changes save only in your own browser; they do not change the public website for other visitors. Export your collection regularly. Import restores saved browser edits and additions against this edition’s baseline.

Explore → Export missing details / conversation prompts produces an entry-based gap report to accompany a monologue or voice conversation. Approximate dates remain approximate; independent spreadsheet lists are not assigned dates from neighbouring event rows.

## Data and evidence

`data/memories.json` is the published baseline, with a matching JavaScript copy for the site. Browser exports contain edits, notes, additions and removals. Supporting evidence has not yet been comprehensively attached or independently verified. Map grouping is a navigation aid, not proof of an event’s location. AI-generated illustrations represent chapters and places; they are not cartographic maps.

Original spreadsheet rows, author correction exports, working backups and unused artwork are excluded from this repository. The local authoring rebuild tool requires Luke’s original attachment and correction export; it is not required to run or deploy the published site.

## Run locally

Run `python -m http.server 8765 --bind 127.0.0.1` in the project folder, then visit http://127.0.0.1:8765/. No package installation or build is required. GitHub Pages serves the root of the main branch.
